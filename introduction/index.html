项目背景与目标

Background & Goals

背景と目標

RLPE（Radiolarian Literature Plate Extractor） 是一款专为放射虫分类学研究设计的智能数据提取工具。放射虫是一类单细胞浮游生物，其硅质骨架化石是深海沉积物中最丰富的微体化石之一，对于确定地质年代、恢复古海洋环境具有重要意义。

RLPE is an intelligent data extraction tool designed for radiolarian taxonomy research. Radiolarians are single-celled planktonic organisms whose silica skeleton fossils are among the most abundant microfossils in deep-sea sediments.

RLPEは放散虫分類学研究のために設計された智能データ抽出ツールです。放散虫は単細胞プランクトンで、そのシリカ骨格化石は深海堆積物中で最も豊富な微化石の一つです。

在放射虫分类学研究中，研究人员需要从大量已发表的科研论文中提取图版中学名与化石样本的对应关系。传统方法需要逐篇阅读论文、手动记录图版信息，既费时又容易出错。RLPE 通过深度学习技术自动完成这些工作，大幅提升效率。

Researchers need to extract species-fossil correspondences from numerous papers. Traditional manual methods are time-consuming and error-prone. RLPE automates this using deep learning technology.

研究者は多数の論文から種名と化石標本の対応関係を抽出する必要があります。従来の手動方法は非効率でエラーが発生しやすいです。RLPEはディープラーニングで自動化します。

RLPE 的目标是帮助研究人员快速从 PDF 文献中提取结构化的图版数据，包括图版图像、面板标签、拉丁学名、地质年代等信息，为构建放射虫分类学知识图谱提供数据支撑。

RLPE aims to help researchers quickly extract structured figure data from PDFs, including images, labels, species names, and geological information, supporting the construction of a radiolarian taxonomy knowledge graph.

RLPEは研究者がPDFから図版画像、ラベル、種名、地質情報などの構造化データを迅速に抽出するのを支援します。

OCR
光学字符识别 OCR

让计算机"看懂"图像中的文字的技术。就像人类用眼睛阅读文字一样，OCR 让计算机能够从扫描的图片或照片中提取出文字内容。在 RLPE 中使用 PaddleOCR 识别图版中的面板标签符号（如 A、B、C、1、2、3 等），并确定它们在图像中的位置。

Optical Character Recognition

Technology that enables computers to "read" text in images. In RLPE, PaddleOCR is used to identify panel label symbols (A, B, C, 1, 2, 3, etc.) in figures and determine their positions.

光学文字認識 OCR

コンピュータが画像内の文字を「読む」技術。RLPEではPaddleOCRを使用して図版内のパネルラベル（A、B、C、1、2、3など）を識別します。

Optical Character Recognition

让计算机从图像中提取文字信息的技术，RLPE 使用 PaddleOCR 识别面板标签符号。

Technology for extracting text from images, used to identify panel labels in figures.

画像からテキストを抽出する技術。

NER
命名实体识别 NER

自然语言处理的一项核心技术，用于从文本中自动识别出特定类型的"实体"。这些实体可以是：人名、地名、机构名、物种名等。在 RLPE 中，专门训练了一个 NER 模型来识别论文中的拉丁学名实体。

Named Entity Recognition

A core NLP technology that automatically identifies specific types of "entities" in text — person names, place names, species names, etc. In RLPE, an NER model is trained to identify Latin species names in papers.

名前付きエンティティ認識 NER

テキストから特定種類の「実体」を自動識別するNLP技術。RLPEではラテン語種名を識別するNERモデルを訓練します。

Named Entity Recognition

从文本中自动识别物种名、地名等特定类型信息的技术，建立命名实体与上下文的关联。

Automatically identifies specific entity types like species names in text.

テキストから特定情報を識別する技術。

LLM
大语言模型 LLM

基于海量文本数据训练的人工智能模型，能够理解和生成人类语言。GPT-4、Gemma、Claude 都是 LLM 的代表。LLM 可以理解上下文、处理复杂推理任务、生成连贯的文本。在 RLPE 中，Gemma 4 用于智能校验学名拼写、解决歧义匹配问题。

Large Language Model

AI models trained on massive text data that can understand and generate human language. GPT-4, Gemma, and Claude are examples. In RLPE, Gemma 4 is used for intelligent species name validation and ambiguity resolution.

大規模言語モデル LLM

海量テキストデータで訓練されたAIモデル。GPT-4、Gemma、Claudeなどが代表例。RLPEではGemma 4で種名の検証を行います。

Large Language Model

能理解和生成人类语言的人工智能系统，在 RLPE 中用于智能校验和歧义消解。

AI systems for understanding and generating human language, used for intelligent validation.

人間の言語を理解生成するAIシステム。

Transformer
Transformer 架构

当前深度学习中最重要的模型架构，2017年由 Google 提出。它通过"注意力机制"（Attention）来理解序列中不同元素之间的关系。这是 GPT、BERT、T5 等几乎所有现代大语言模型的基石。

Transformer Architecture

The most important deep learning architecture, proposed by Google in 2017. It uses "attention mechanisms" to understand relationships between elements. This is the foundation of GPT, BERT, T5, and almost all modern LLMs.

Transformer アーキテクチャ

2017年にGoogleが提案した最も重要な深層学習アーキテクチャ。「注意機構」を使用して要素間の関係を理解します。

现代深度学习的核心架构，通过注意力机制理解上下文关系，是 GPT、BERT 等模型的基础。

Core architecture in modern deep learning using attention mechanisms.

現代のディープラーニングの中核アーキテクチャ。

微调
模型微调 Fine-tuning

在一个已经预训练好的大模型基础上，使用特定领域的数据进行进一步训练，使模型更适应特定任务。在 RLPE 中，可以使用放射虫分类学的专业文献微调模型，提升识别放射虫学名的能力。

Fine-tuning

Further training a pre-trained model with domain-specific data to make it better suited for specific tasks. In RLPE, radiolarian taxonomy literature can be used for fine-tuning to improve species name recognition.

ファインチューニング

事前訓練済みモデルを特定分野のデータで追加訓練。RLPEでは放散虫分類学の文献でモデルを微調整できます。

Fine-tuning

使用特定领域数据对预训练模型进行进一步训练，提升专业领域的识别准确率。

Further training a model with domain-specific data for better performance.

量化
模型量化 Quantization

将模型参数从高精度（如 32 位浮点数）转换为低精度（如 8 位或 4 位整数）的技术。这可以大幅减少模型体积（2–4 倍）和计算量，使大模型能够在消费级 GPU 甚至 CPU 上运行。

Quantization

Converting model parameters from high precision (e.g., float32) to lower precision (e.g., int8 or int4). This significantly reduces model size (2–4×) and computational requirements, enabling large models to run on consumer GPUs or even CPUs.

量子化

モデルパラメータを高精度から低精度に変換する技術。モデルサイズを2–4倍削減し、GPUやCPUでも実行可能にします。

Quantization

降低模型精度以减少计算资源需求的技术，INT4/INT8 量化可大幅减少显存占用。

Reduces model precision to decrease resource needs; INT4/INT8 quantization saves VRAM.

リソース要件を減らす技術。

图像分割
图像分割 Image Segmentation

将图像划分为多个有意义的区域的技术。与简单地检测物体边界框不同，图像分割可以精确地识别图像中每个像素属于哪个类别或物体。在 RLPE 中用于将包含多个子图的图版分割为独立的单个面板图像。

Technology that divides an image into meaningful regions. Unlike simple bounding box detection, it precisely identifies which pixels belong to which object. In RLPE, it's used to separate individual panels from composite figures.

快速安装

Quick Install

クイックインストール

三步完成环境搭建

Three steps to get started

3ステップで開始

1. 克隆仓库

git clone https://github.com/syxscott/RLPE-Radiolarian-Plate-Extractor.git
cd RLPE-Radiolarian-Plate-Extractor

2. 安装依赖

pip install -r requirements.txt
pip install "opendataloader-pdf>=0.0.0"  # 可选

3. 启动服务

# Web 模式
python run_web_server.py

# 命令行模式
python -m rlpe --pdf-dir data/pdfs --work-dir work

依赖要求

Python ≥ 3.11 · GROBID 服务（或使用 OpenDataLoader） · Java 11+（使用 OpenDataLoader 时需要） · GPU 可选（用于 SAM2 / Gemma 加速）

常见问题

FAQ

よくある質問

关于 RLPE 的常见问题解答

Frequently asked questions about RLPE

RLPEに関するよくある質問

Gemma 4 加载失败怎么办？What if Gemma 4 fails to load?Gemma 4の読み込みに失敗した場合？

检查 gemma_model_path 是否正确、模型目录是否完整、Transformers 版本是否支持该模型类型。如果显存不足，可以开启 4-bit 量化（默认开启）。

Check that gemma_model_path is correct, the model directory is complete, and the Transformers version supports the model. Enable 4-bit quantization if VRAM is limited (enabled by default).

gemma_model_pathが正しいか、モデルディレクトリが完全か、Transformersのバージョンがモデルをサポートしているかを確認してください。

CUDA OOM 怎么办？How to handle CUDA OOM?CUDA OOMの対処法？

降低并发数、关闭 Gemma 或降低调用规模、关闭 bfloat16 或调整量化策略。建议先用小样本（5–10 篇）试跑确认资源占用。

Reduce concurrency, disable Gemma or reduce call scale, disable bfloat16, or adjust quantization strategy. Test with a small sample (5–10 papers) first.

並列数を減らす、Gemmaを無効にする、bfloat16を無効にする、量子化戦略を調整するなどの対処があります。

panel 裁剪效果不好怎么办？What if panel cropping is poor?パネル切り抜きの品質が悪い場合？

检查 output/figures/regions 目录中的中间产物，调整分割相关阈值、图片 DPI 或 SAM2 参数（min_panel_score、render_dpi）。

Check intermediate results in output/figures/regions, adjust segmentation thresholds, image DPI, or SAM2 parameters (min_panel_score, render_dpi).

output/figures/regionsの中間結果を確認し、分割閾値、DPI、SAM2パラメータを調整してください。

支持哪些 PDF 格式？Which PDF formats are supported?対応PDF形式は？

支持几乎所有常见学术 PDF 格式，包括数字原生 PDF 和扫描版 PDF（需 OCR 支持）。对于老文献的扫描版，建议使用 OpenDataLoader 的 hybrid OCR 模式或提高渲染 DPI。

Supports almost all common academic PDF formats, including born-digital and scanned PDFs (OCR required). For older scanned literature, use OpenDataLoader's hybrid OCR mode or increase render DPI.

デジタルPDFとスキャンPDFの両方に対応。古いスキャン文献にはOpenDataLoaderのハイブリッドOCRモードを推奨。

可以处理非放射虫的文献吗？Can it handle non-radiolarian literature?放散虫以外の文献も処理可能？

RLPE 的设计是针对放射虫图版优化的，但底层技术（版面分析、面板分割、OCR、NER）具有通用性。通过自定义训练数据和调整匹配规则，可以适配其他微体化石类型（如有孔虫、硅藻、钙质超微化石等）。

RLPE is optimized for radiolarian plates, but the underlying tech (layout analysis, panel segmentation, OCR, NER) is general-purpose. With custom training data and rule adjustments, it can be adapted to other microfossil types (foraminifera, diatoms, calcareous nannofossils, etc.).

RLPEは放散虫図版に最適化されていますが、基盤技術は汎用的です。カスタム訓練データとルール調整により、他の微化石タイプにも適応可能です。

GROBID 和 OpenDataLoader 如何选择？GROBID vs OpenDataLoader?GROBIDとOpenDataLoaderの選択？

GROBID 是默认方案，提供成熟的学术文献 TEI 解析。OpenDataLoader 是可选替代方案，在版面分析和 figure-caption 关联方面更精准（Benchmark #1），且不依赖外部 GROBID 服务，但需要 Java 11+。建议在处理大量扫描件或需要更精准图版检测时使用 OpenDataLoader。

GROBID is the default, providing mature academic TEI parsing. OpenDataLoader is an alternative with better layout analysis and figure-caption linking (Benchmark #1), and no external service dependency, but requires Java 11+. Use OpenDataLoader for large scan batches or when you need more precise figure detection.

GROBIDはデフォルトで成熟したTEI解析を提供。OpenDataLoaderはより高精度なレイアウト分析が可能ですがJava 11+が必要です。
